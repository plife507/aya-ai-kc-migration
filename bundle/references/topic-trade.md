# TRADE Topic

## Purpose
TRADE is the trading-system build lane.

Use it for:
- TRADE repo work
- DSL understanding and examples
- play design
- backtests
- headless operation
- knowledge-base / ingest workflow
- shadow/live architecture
- strategy iteration
- docs/reviews/opinions for the TRADE system

## Core working posture
- query the knowledge base before ingesting new info
- review DSL docs and existing plays before writing a new play
- treat the DSL as expressive, not as a last resort
- build -> test -> iterate with evidence
- distinguish system-operation success from first-pass strategy-quality success

## Working rule for Aya
- do not shortcut into shallow play writing
- orient first:
  - query knowledge
  - review DSL/examples
  - only then ingest/build
- use TRADE as the lane for serious strategy/system development, not mixed casual HQ chat

## What does not belong here
Avoid putting KC execution work, Slack/Jobber operations, or personal LIFE discussion here unless it directly informs TRADE strategy or direction.
