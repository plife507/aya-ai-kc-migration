# KC Recurring Work Reference

Purpose: quick reference for recurring KC jobs, who usually performs them, and the recurring economics/notes Nathan wants preserved.

Use this as an operating reference, not as the sole source of truth. Verify against Jobber when details affect a live write or Slack post.

## Fields

- **Job #**: visible Jobber job number
- **Client**: client / account name
- **Scope**: recurring work description
- **Usual Sub / Crew**: who normally performs it
- **Recurring Economics**: per-visit sale/sub context when known
- **Notes**: recurring handling notes
- **References**: verified Jobber links when available
- **Last Confirmed**: when this reference was last updated
