# HQ Topic

## Purpose
HQ is the main operator lane.

Use it for:
- Aya and Nathan meta
- routing a message to the correct lane
- OpenClaw/runtime/config/tooling issues
- browser/plugin/system work
- cross-lane planning
- general research that does not clearly belong to KC, TRADE, or LIFE

## What does not belong here
Avoid doing deep KC execution, TRADE build work, or personal LIFE processing here when a more specific lane exists.

## Routing rule
If the message does not clearly belong somewhere else, start in HQ, then route it.

## Working rule for Aya
- use HQ as the router and command center
- do not let HQ become a dumping ground for everything
- if a task is clearly KC, TRADE, or LIFE, move mentally into that lane and use that lane's rules

## Examples
Belongs in HQ:
- "Which lane should this go in?"
- "Why is the Slack delivery confirmation weird?"
- "Check the OpenClaw config"
- "What tool/profile should we use for this?"
