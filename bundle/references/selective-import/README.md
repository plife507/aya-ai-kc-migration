# Selective Import

Purpose: carry forward only old Aya material that increases real operational efficiency in the current AYA-CLAW workspace.

This folder is intentionally selective.

Included here only if the content does at least one of these:
- improves execution quality for common work
- prevents repeat mistakes
- sharpens system/tool choice under pressure
- preserves durable operating lessons that still fit the current architecture

Excluded on purpose:
- stale runtime topology
- deprecated path assumptions
- old agent structure
- migration ceremony
- raw daily logs
- anything secret-bearing or machine-specific unless rewritten safely
